# Production templates

`active/index35_cam_sole.html` is the production browser interface rendered by
`../app35_cam_sole.py` (release V13).

The directory and filename are intentionally unversioned. Application versions
are preserved under `../legacy/`; older templates are under
`../legacy/templates/`.

The standalone focus utility has its own template at
`../codesharpnessmeasure/templates/index.html`.
